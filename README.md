# disappear-site

Public pages for the game disappear, served by GitHub Pages:

- `/` home
- `/privacy/` privacy policy (the URL for App Store Connect, Google Play and the in-game Settings link)
- `/support/` support page (App Store support URL)
- `/daily/` the page a shared Daily result links to (`?n=20261123` shows "Daily #20261123", the Daily's day; other values keep "Today's Daily"): what the game is and where to get it; `preview.png` is the link preview (Open Graph, 1200x630). The store buttons say "coming soon" until the game is live; the comment in the page has the links to put in.

Plain HTML and CSS, no build step. The wordmark uses Gluten ExtraBold (SIL Open Font License 1.1, see `fonts/OFL.txt`).
